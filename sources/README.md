# Sources

Ten katalog jest przeznaczony wyłącznie na **lokalne, prywatne materiały**
użytkownika. Jego zawartość jest ignorowana przez Git; w repozytorium pozostają
tylko ten plik i puste katalogi.

- `books/` — książki, rozdziały i notatki do książek;
- `articles/` — artykuły i dokumentacje;
- `notes/` — pytania, podsumowania i kontekst.

Nie umieszczaj tu danych pacjentów, dokumentacji medycznej, sekretów, nagrań
innych osób ani materiałów, których nie masz prawa przetwarzać. Dane używane do
testów publicznych powinny być syntetyczne i trafić do `tests/fixtures/`.
